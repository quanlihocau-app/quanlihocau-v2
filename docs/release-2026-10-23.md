## Rollback

1. **Chỉ anh Huân (quyền Vercel):** Deployments → bản production liền trước → Instant Rollback. Việc này đổi code, không đổi database.
2. Code cũ chạy được với hai migration mới. Không xóa bảng `PrintJob`, không xóa cột `auditReadTokenHash`, không xóa index.
3. Rollback **không** trả giá catalog về số cũ. Đơn đã phát hành giữ nguyên số tiền trên đơn (kể cả 99.000đ / 179.000đ). Code cũ tính đơn mới theo hằng số trong bản code đó. Nếu bắt buộc trả catalog về số đã SELECT ở trên, chỉ anh Huân chạy `UPDATE` trên đúng 3 dòng `SubscriptionPlan`. Không có migration down.
4. Nếu rollback vì cookie đăng nhập: bản mới cố ý xóa cookie không giải mã được. Quay lại bản cũ thì người còn cookie cũ có thể kẹt đăng nhập lần nữa và phải xóa cookie trình duyệt.
